Write two sentences.

Write two sentences.

She ____.

WORD BANK:
ITEMS: see STIMULUS (2 items)

2. ______________________________
3. ______________________________
4. ______________________________

Personal answer.

Check: the student's sentences should be true for that student. Usually sentences use the Present Simple; "now" sentences use am/is/are + V-ing.
